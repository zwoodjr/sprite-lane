# sprite-lane

## Play on GitHub Pages

Branch `gh-pages` has the game ready to host.

1. Open **https://github.com/zwoodjr/sprite-lane/settings/pages**
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: **gh-pages** / folder: **/ (root)** → Save

Then play at: **https://zwoodjr.github.io/sprite-lane/**
