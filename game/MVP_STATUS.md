# Wanderer MVP Status (repo mirror)

Authoritative copy for Project Context: store `docs/mvp-status.md`.

## Playable

- Godot 4.3 project in this folder opens cleanly.
- Top-down move / aim / shoot; simple enemies; hub + 3 spokes placeholder map.
- Flow: Main → Easy/Medium → Rook/Cinder → Deploy → lockout → extract windows → Last Extract → success/wipe.
- Skip window raises Threat Level; extract pays Scrap/XP stubs; wipe uses classic insurance stub.
- Skateboard mount (F); scooter/dirt-bike unlock stubs; armor/weapon/pet thin stubs.
- Optional **Fast timers (dev)** on mode select.

## Out of slice

Hard+ modes, Ash/Quill, real art, pet AI, full gear trees, stash UX, audio, monetization.

## Run

Open `project.godot` in Godot 4.3+ → F5. See `README.md`.
